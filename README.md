# 🏢 HRMSP — HR Management System (WinForms)

A desktop Human Resource Management System built with **C# WinForms** and **MySQL**. Manages employees, departments, designations, leave requests, and monthly salary slips through a stored-procedure-backed data layer.

## ✨ Features

- **Secure login** — email/password authentication against the employee table.
- **Department & Designation management** — full CRUD for organizational structure.
- **Employee management** — records including department, designation, salary, bank details, and nationality.
- **Leave management** — request, approve/reject, and track leave with day counts and reasons.
- **Salary slips** — generate monthly slips with allowances (food, medical, travel), bonuses, advances, and leave deductions; supports yearly reporting per employee.
- **Stored-procedure data layer** — every module (`EmployeeSp`, `DepartmentSp`, `DesignationSp`, `LeaveSp`, `SalarySlipSp`, `ContactSp`) is driven by a single reusable `DatabaseHelper` class.

## 🗄️ Database Schema

The `database/hrmsdb.sql` file creates the `HRMSDB` database with:

| Table         | Purpose                                      |
|---------------|-----------------------------------------------|
| `dep_tb`      | Departments                                   |
| `des_tb`      | Designations                                  |
| `emp_tb`      | Employees (linked to department & designation)|
| `leave_tb`    | Leave requests                                |
| `salaryslip`  | Monthly salary slips                          |
| `contact_tb`  | Contact/inquiry messages                      |

It also defines stored procedures (`EmployeeSp`, `DepartmentSp`, `DesignationSp`, `LeaveSp`, `SalarySlipSp`, `ContactSp`) that handle INSERT/SELECT/UPDATE/DELETE and login logic for each module, so the C# app never writes raw SQL against the tables directly.

## 🚀 Getting Started

### Prerequisites
- **Visual Studio 2019 or later** (with .NET desktop development workload)
- **.NET Framework 4.7.2**
- **MySQL Server** (locally or remote)
- **MySQL Connector for .NET** — restored automatically via NuGet (`MySql.Data`)

### 1. Clone the repository
```bash
git clone https://github.com/MuhammadAhmad78/hrms-Winforms.git
cd hrms-winforms
```

### 2. Set up the database
Open MySQL Workbench (or the `mysql` CLI) and run:
```bash
mysql -u root -p < database/hrmsdb.sql
```
This creates the `HRMSDB` database, all tables, and all stored procedures.

### 3. Configure your connection string
Open `HRMSP/App.config` and update the placeholder with your real MySQL password:
```xml
<add name="HRMSDBConnection"
     connectionString="Server=localhost;Database=hrmsdb;Uid=root;Pwd=YOUR_MYSQL_PASSWORD;"
     providerName="MySql.Data.MySqlClient"/>
```
**Never commit your real password to GitHub** — `App.config` is tracked in this repo with a placeholder on purpose; just don't replace the placeholder and push it back with your real one.

### 4. Open and restore packages
Open `HRMSP.sln` in Visual Studio. It will prompt to restore NuGet packages automatically (or right-click the solution → **Restore NuGet Packages**).

### 5. Build and run
Press **F5** (or **Build → Start Debugging**). The login screen (`frmLogin`) will launch first.
